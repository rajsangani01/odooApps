List View PDF Reports

Download and print available PDF reports directly from record rows in any Odoo List (Tree) View with 1-click simplicity.

Developed by Rajkumar Sangani

Why Install This App?

Boost daily operational efficiency and eliminate repetitive navigation clicks.

85% Time Saving

Generate quotes, invoices, or delivery slips instantly without opening the record form view first.

Hover Dropdown

Hovering over the PDF button automatically opens an unclipped, high z-index popover menu with report options.

Zero RPC Overhead

Report metadata is cached per model during initial view load. Adds 0 extra RPC requests per record row.

Key App Features

Smart Dynamic Discovery

Automatically discovers active PDF reports associated with the current model accessible to the user.

Conditional Display

The PDF dropdown button renders ONLY when at least one report is available, keeping list views clean.

100% Odoo Security Compliant

Enforces record access rights (ACLs), user security groups, record rules, and multi-company filters.

Admin Control Panel

Toggle report visibility per-report in List View via Settings → Technical → Reporting → PDF Reports in List View.

User & Setup Guide

1
Install App

Install list_view_pdf_reports from Apps module list in Odoo 19.

2
Open List View

Go to Sales, Invoices, or Contacts list view and hover over the PDF ▼ button on any row.

3
Direct Download

Click your desired report option to trigger immediate PDF generation and download.
