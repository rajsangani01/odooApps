## Overview

`list_view_pdf_reports` adds a context-aware **PDF Reports** dropdown directly to every record row in Odoo List (Tree) Views. Users can view and trigger PDF report generation in a single click without opening the form view.

---

## Key Features

1. **Direct Row Action**: Print invoices, quotations, or custom reports directly from List Views.
2. **Auto-Hover Dropdown**: Mouse hover automatically reveals unclipped, high z-index popover options.
3. **Smart Discovery Engine**: Dynamically fetches active PDF reports matching record models.
4. **Conditional Display**: The PDF button renders ONLY when at least one report is available.
5. **Zero RPC Overhead**: Cached model report metadata ensures 0 extra server queries per record row.
6. **Strict Security Compliance**: Fully enforces Odoo ACLs, user security groups, record rules, and multi-company filtering.
7. **Admin Controls**: Manage report visibility per-report in *Settings -> Technical -> Reporting -> PDF Reports in List View*.

---

## Installation

1. Copy the `list_view_pdf_reports` directory into your Odoo addons path.
2. Update the Apps List in developer mode.
3. Install **List View PDF Reports**.
